# 双循环 RPG —— 日常 × 地下城（Pygame 原型）

「日常 + 地下城」双循环 RPG：日常聊天/好感/记忆 ↔ 地下城爬塔/战斗/掉落，商店、装备、词条、伙伴、感情线逐步叠加上来。

## 运行

```bash
cd rpg
python run_game.py            # 启动图形界面
python run_game.py --smoke    # 无窗口自检
python main.py                # 核心数据结构演示
python demo_dialogue.py       # 对话系统演示
python demo_battle.py         # 战斗系统演示
python demo_dungeon.py        # 地下城探索演示
python demo_main.py           # 状态机 + 存档读档演示
```

## 核心系统

- **日常（城镇）**：休息/锻炼/打工/聊天；好感、感情线、招募伙伴、伙伴技能升级、背包、修道院忏悔、脱衣/换装。
- **城市逛街**：城镇「商店」→ 城市街道，7 家分类店铺（武器/防具/饰品/药水/技能书/服装/杂货）+「随便逛逛」8 种随机街头事件（促销/扒手/传闻/卖艺/小贩/斗殴/流浪猫/无事）。
- **商店分类 + 动态价格**：价格受 **荣誉/恶名 × 当日行情 × 供需** 影响；买得多需求上升（更贵），卖得多供给上升（更便宜）；每家店有独立货架。
- **地下城**：每层最多 4 个随机房间（敌人/冒险者/伤员/宝箱/陷阱/入口），战斗胜利掉落金币/材料/装备/技能书。
- **战斗**：速度排序、普攻/技能、蓝耗/冷却、暴击/闪避/吸血/中毒/减CD、多敌人点选目标、伙伴自动行动（伙伴同时显示 HP/MP 条）。
- **伙伴技能**：伙伴有 LP/MP 双资源，技能随等级强化（Lv1-3）；艾琳升到 Lv2 解锁【补蓝术】，会优先给缺蓝的队友回蓝。
- **技能遗忘书**：消耗品，可遗忘一个已学技能、空出技能槽（普攻不可遗忘）。
- **服装系统**：冒险者装 / 华服 / 酒馆围裙等外观服装，购买后可换上；穿特殊服装 NPC 会有不同反应，脱光则有「恶趣味」彩蛋。
- **敌人 AI**：优先攻击治疗型伙伴（约 73% 概率打治疗者）。
- **荣誉值**：正=荣誉、负=恶名、0=无名；影响商店价格、酒馆入住、NPC 台词。
- **感情线**：约会推进（未开始→暧昧→心动→恋人）；古德是男性哥们，不可约会，脱衣反应为哥们式嫌弃/调侃。
- **艾琳告白线（已实装）**：5 个关键事件（雨夜留宿/旧伤/打烊之后/她的担心/告白前夜）→ 告白场景 → 4 个结局（恋人/并肩/错过/逃避）。
- **存档**：`save.json`（JSON），`Game.save()/load()`。

## 素材接入层

- `pygame_game/assets.py`：按**逻辑名**从 `assets/` 加载图片 / 音频 / 字体，**缺失自动回退占位色块与合成音**，所以可以一份份慢慢替换。
- 目录约定与命名规则见 **`assets/README.md`**。
- 替换素材**不用改代码**：把文件按约定路径放进去，重启游戏即可生效。
- 支持可选 `assets/manifest.json` 把逻辑名映射到自定义文件名。

## 本轮改进（对标行业标杆）

按「风险 / 目标 / 战斗深度 / 内容 / 反馈 / 构筑 / 成长」七个短板补：

- **目标（委托板）**：城市新增「委托板」，3 个短期委托（讨伐 N 只 / 抵达 N 层 / 带回 N 金币 / 帮助伤员），完成可领金币+经验，替代「只有变强」的模糊目标。
- **风险**：战败除扣一半金币外，还会**随机丢失一件背包物品**；深层收益改为每层 ×1.2（越深越香，但死得越疼）。
- **战斗深度**：敌人有**特殊技**（哥布林投石 / 野狼撕咬 / 毒蜘蛛喷吐 / 幽灵尖啸 / 骷髅骨刺 / 巨魔横扫 / 深渊恶魔爆发），不再只是互相普攻。
- **内容**：地下城从 2 层扩到 **4 层**，新增毒蜘蛛 / 幽灵 / 骷髅兵 / 巨魔 / 深渊恶魔。
- **反馈（游戏手感）**：战斗加入**伤害飘字**（暴击更大更金黄）、**受击闪白**、**屏幕震动**、**程序化打击/治疗音效**（无素材，正弦波合成）。
- **构筑（流派）**：词条组合出四套流派——
  - **暴击流**（暴击率 ≥40%）：暴击伤害 1.8x → 2.2x
  - **毒流**（毒伤 ≥10）：中毒持续 3 → 5 回合
  - **吸血流**（吸血 ≥30%）：吸血量 ×1.5
  - **闪避流**（闪避 ≥30%）：闪避后反击 50% 攻击
- **成长**：锻炼攻击收益从 +2 降到 +1，放缓曲线。
- **每日事件**：每日随机「平静/集市日/冒险者节/魔物躁动」，带来物价/经验/金币变化。
- **存档完整性**：委托进度、市场行情、今日事件都会写进存档。
